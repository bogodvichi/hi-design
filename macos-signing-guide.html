1

创建 Developer ID 证书

代码签名需要 Developer ID Application 证书。这是 Apple 为分发到 Mac App Store 外的应用提供的证书类型。

1.1 生成 CSR（证书签名请求）

  1. 打开 Mac 上的「钥匙串访问」应用（Keychain Access）
  2. 菜单栏选择 钥匙串访问 → 证书助理 → 从证书颁发机构请求证书
  3. 填写信息：
    • 用户电子邮件地址：你的 Apple ID 邮箱
    • 常用名称：你的名字或公司名
    • CA 电子邮件地址：留空
    • 请求是：选择存储到磁盘
  4. 保存 CertificateSigningRequest.certSigningRequest 文件

1.2 在 Apple Developer 网站申请证书

  1. 访问 Apple Developer Portal 并登录
  2. 进入 Certificates, Identifiers & Profiles
  3. 点击 + 按钮添加新证书
  4. 选择 Developer ID Application（注意不是 iOS Distribution 或 Mac App Distribution）
  5. 上传刚才生成的 .certSigningRequest 文件
  6. 下载生成的 .cer 证书文件

1.3 安装证书

  1. 双击下载的 .cer 文件
  2. 证书会自动安装到「钥匙串访问」的登录钥匙串
  3. 在「钥匙串访问」中搜索证书名称，展开后确认有私钥（🔑 图标）
💡 重要提示

如果证书下没有私钥，签名会失败。请确保 CSR 是在当前 Mac 上生成的，私钥会自动存储在该 Mac 的钥匙串中。

2

获取必要信息

2.1 获取 Team ID

  1. 登录 Apple Developer Portal
  2. 点击右上角你的账号名 → Membership Details
  3. 找到 Team ID（10 位字符串，如 ABCDE12345）

2.2 创建应用专用密码

Apple 不允许用真实密码做公证，必须创建应用专用密码：

  1. 访问 appleid.apple.com 并登录
  2. 进入 登录与安全 → App 专用密码
  3. 点击 生成 App 专用密码
  4. 输入标签名称（如 Open Design Notarize）
  5. 复制生成的密码（格式如 abcd-efgh-ijkl-mnop）
⚠️ 注意

应用专用密码只显示一次，请务必保存好。如果丢失，需要重新生成。

3

配置环境变量

将签名和公证所需的环境变量配置到 shell 配置文件中，避免每次手动输入。

3.1 编辑配置文件

打开终端，编辑 ~/.zshrc 文件（如果使用 bash，则编辑 ~/.bash_profile）：

bash 
# 使用默认编辑器打开
open ~/.zshrc

# 或者使用 nano
nano ~/.zshrc

# 或者使用 VS Code
code ~/.zshrc

3.2 添加环境变量

在文件末尾添加以下内容（替换为你的真实信息）：

bash 
# Open Design 打包签名/公证配置
export APPLE_ID="your-email@example.com"
export APPLE_APP_SPECIFIC_PASSWORD="xxxx-xxxx-xxxx-xxxx"
export APPLE_TEAM_ID="YOURTEAMID"

3.3 使配置生效

bash 
source ~/.zshrc
💡 验证环境变量

在终端中运行 echo $APPLE_ID，确认输出正确的邮箱地址。

4

执行打包

4.1 仅签名（不公证）

如果只需要代码签名，不需要公证：

bash 
pnpm tools-pack mac build --to dmg --signed

4.2 签名 + 公证（推荐）

完整的签名+公证流程，生成 DMG 和 ZIP：

bash 
pnpm tools-pack mac build --to all --signed --notarize

4.3 可选参数说明

参数说明
--to app仅构建 .app 目录
--to dmg构建 DMG 安装包
--to zip构建 ZIP 压缩包
--to all构建 DMG + ZIP
--signed启用代码签名
--notarize启用公证（需配合 --signed）
5

验证结果

5.1 验证签名

bash 
# 验证 .app 签名
codesign -vv --deep --strict /path/to/Open\ Design.app

# 查看签名详情
codesign -dvv /path/to/Open\ Design.app

5.2 验证公证

bash 
# 检查公证状态
spctl -a -vv /path/to/Open\ Design.app

# 查看公证详情
xcrun stapler validate /path/to/Open\ Design.app

常见问题

打包时提示找不到证书？

  • 确认证书安装在「登录」钥匙串，而不是「系统」
  • 确认证书类型是 Developer ID Application
  • 确认证书没有过期
  • 确认证书下有对应的私钥（🔑 图标）

公证失败？

  • 检查三个环境变量是否都正确设置
  • 确认 APPLE_APP_SPECIFIC_PASSWORD 是应用专用密码，不是 Apple ID 真实密码
  • 确认 APPLE_TEAM_ID 是 10 位字符串
  • 网络问题会导致临时失败，项目内置了 3 次重试机制

Windows 上能签名吗？

不能。 codesign 和 xcrun notarytool 是 Apple 的 macOS 专属工具。必须在 macOS 上执行签名和公证。
