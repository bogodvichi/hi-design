# HUI 设计系统(海康 HUI · 蓝 / Light)

> Category: Professional & Corporate
> 面向安防与监控软件的企业级设计系统:品牌蓝主色、数据密集布局、紧凑控件、锐利圆角,以及内置的 h-icon 图标字体。

本包由海康 HUI「HUI-蓝」浅色主题的设计 token 整理而成。所有值以官方 token 表为准;`tokens.css` 采用**双层结构**:上层是 56 个 Open Design 契约 token(供通用组件与跨品牌切换),下层是完整的 HUI 原生 token(`--h-*` 命名空间,供海康组件精确还原)。

## 视觉基调

HUI 服务于安防管理平台、监控客户端、设备配置后台等 B 端场景。界面追求**清晰、克制、高信息密度**:大量表格、表单、树与状态标签共存,视觉噪音要低,层级要一眼可辨。

- 风格定位:企业级、数据密集、专业可靠。
- 色彩克制:大面积中性灰白,品牌蓝只用在关键信号上。
- 控件紧凑:默认控件高度 32px,圆角锐利(2–10px),留白按 4px 栅格。
- 设计意图:保持 HUI 家族的辨识度,同时确保可读性与可访问性。

## 色彩

- **品牌主色 `--accent` = `#2080F7`(HUI 蓝)**:hover 变亮 `#50A2F9`,active 变暗 `#1461CC`;主色上的文字 `--accent-on` = `#FFFFFF`。
- **中性文字**采用半透明黑,层级由不透明度区分:正文 `rgba(0,0,0,.7)`、次要 `.5`、三级/元信息 `.4`、禁用 `.3`。
- **背景**:页面画布 `--bg` = `#F5F5F5`,卡片/容器 `--surface` = `#FFFFFF`(灰底白卡)。
- **边框**:契约层 `--border` = `rgba(0,0,0,.2)`、`--border-soft` = `rgba(0,0,0,.12)`;原生层完整保留四级(primary `.3` / secondary `.2` / tertiary `.12` / disabled `.08`)。
- **语义色**:成功 `#1DB84C`、警告 `#FF832B`(橙)、危险 `#E6202A`;原生层另含 info、remind、link、chart 全系列及其 hover/active/disabled/secondary/tertiary 状态。

用法:主色只承载主操作、选中态、链接、焦点等关键信号,一屏内克制使用;大面积区域用中性色;语义色仅用于状态表达,不做装饰。

## 字体与排版

- **字体栈**:标题与正文同栈,首选微软雅黑 —— `"Microsoft YaHei", "微软雅黑", "PingFang SC", "Hiragino Sans GB", system-ui, sans-serif`;等宽用系统默认。
- **字号阶(8 级,取自 token 表)**:12 / 14 / 16 / 18 / 20 / 24 / 28 / 32(`--text-xs … --text-4xl`);更大展示字号(36–42)与全部原生字号保留在 `--h-font-size-*`。
- **字重**:正文/说明 400,标题(H1–H5)500;记于原生层 `--h-font-weight-regular/medium`。
- **行高**:HUI 规则为「字号 × 1.5,逢单减 1」(如 28→42、14→20);每个语义级别的精确 px 行高保留在 `--h-line-hight-*`。契约层用无单位比例:正文 1.5、标题 1.25。

标题承载层级与信息骨架,正文优先可读性与扫读效率;同一语义级别在全平台保持一致的字号/行高/字重。

## 间距与布局

- **间距**基于 4px 栅格:`--space-1…12` = 4 / 8 / 12 / 16 / 20 / 24 / 32 / 48;原生层保留 `--h-base-size-*`(4–80)与 `--h-core-space-*`(xxs–xxl)全档。
- **容器**:最大内容宽 `--container-max` = 1920px(适配安防大屏);两侧留白桌面 32 / 平板 24 / 手机 16。
- **区块节奏**:纵向区块间距桌面 80 / 平板 56 / 手机 40。
- 保持垂直节奏一致,模块对齐到可预测的栅格,先用留白划分区域,再考虑边框与分隔线。

## 圆角、阴影与动效

- **圆角**锐利:契约 `--radius-sm/md/lg` = 4 / 6 / 10,`--radius-pill` = 9999;原生层保留 none/2/4/6/10/20/round 全 7 档。
- **阴影**:契约 `--elev-raised` 取 z1;原生层三档 `--h-shadow-z1/z2/z3`(浮层、弹层、模态由浅到深)。
- **焦点**:`--focus-ring` 用 HUI 橙对比色 `#FF832B` 的 3px 外环,确保键盘可见。
- **动效**:过渡短而克制,`--motion-fast` 150ms / `--motion-base` 200ms,统一缓动 `cubic-bezier(0.2, 0, 0, 1)`;hover / focus-visible / active / disabled / loading 状态需显式覆盖。

## 图标

内置 h-icon 图标字体(`fonts/` 下 woff2 / woff / ttf / eot / svg 全格式 + `h-icon.css`)。

- font-family 为 `h-icon`,原生层记为 `--h-font-icon`。
- 用法:元素加 `class="icon h-icon-<name>"`,通过 `::before` 的 Unicode 码点渲染,如 `.h-icon-add`、`.h-icon-alarm`、`.h-icon-angle-down`、`.h-icon-arrow-right`。
- 纯图标按钮必须有 tips 提示,提示文字用动词或动宾结构(如"删除"、"移动位置")。
- 出海产品的图标与名称需适应国际化,避免仅适用于单一地区的信息。

> 说明:Open Design 目前尚无「把包字体自动注入任意 artifact」的统一管线,故图标在本包 `components.html` 内可用;其他页面使用 HUI 图标时需手动引入一次 `@font-face`。

## 组件

覆盖安防后台高频控件,均通过 token 表达:

- **按钮**:主(`--accent`)、次(描边)、文字、危险(`--danger`),以及纯图标按钮;按钮文案用动词或动宾结构(如"新增设备""导出")。
- **表单**:标签 + 必填 `*` 标记 + 输入框 + 格式限制提示 + 校验反馈;下拉选择、开关。标签后不加冒号。
- **表格**:表头中性弱化,行以 `--border-soft` 分隔,状态列用语义标签。
- **卡片/面板**:统一圆角、留白与 `--elev-raised` 阴影策略。
- **状态标签(badge)**:在线/离线/升级中等,用语义色的低饱和底 + 实色文字。
- **反馈**:模态弹窗(确认/成功/失败/告警)、操作提示 toast、缺省态(暂无数据/异常/加载)。

## 文案与语气

遵循海康《信息设计规范》文案部分,五项原则:**贴近用户、指导性、简洁性、一致性、准确性**。核心可执行规则:

- **按钮**用动词/动宾;**标签**表状态用「已 xx / 未 xx / xx 中」;**提示反馈**用完整句。
- **提示句式**:成功 `{操作}{对象}成功。`;失败 `{操作}{对象}失败,{原因}。`;先结果后原因。
- **术语统一**:同一概念统一用词(如统一用「编辑」而非「修改」、「账号/用户名」按规范取舍)。
- **数字与单位**:统一阿拉伯数字;范围用波浪线 `1~64 个字符`;数字与单位符号间空格(`500 KB`);分隔号 `/` 前后不加空格。
- **标点**:中文标点用全角;"暂无数据"等空态文案不加句末句号(翻译时另标)。
- **菜单**用「名词 + 动词」结构(如"设备管理"),不用动宾结构(如"配置设备")。
- 避免人称代词("请您…"→"请…")、代码标识符(null)、"内部/未知错误"等模糊表述。

## 双层 Token 架构

`tokens.css` 的 `:root` 同时声明两层,任何 artifact 只需整块复制:

- **契约层(56 个)**:Open Design 共享 schema token(`--bg`、`--fg`、`--accent`、`--text-*`、`--space-*`、`--radius-*` 等)。它是入场券,保证 HUI 能被通用组件消费、跨品牌切换、通过仓库 guard。值由 HUI 原生 token 映射而来。
- **HUI 原生层(`--h-*`,C-extension)**:HUI「HUI-蓝」主题的完整原生 token,忠实保留颜色全系列与状态、`--h-base-size/radius`、`--h-core-space/component-height`、组件级度量、`--h-font-size/line-hight` 全阶、`--h-shadow-z1/z2/z3` 等。名字中若含括号/等号等非法 CSS 字符(如导出时的 `(=margin,=padding)`)已规范化为合法变量名,**值一字未改**。

原则:通用/跨品牌组件只引用契约层;HUI 专有的细分层级与状态用原生层。原生 token 经 `--h-` 前缀在共享 schema 的扩展白名单登记。

## 反模式

- 不要在复制的 `:root` 之外散写裸色值;需要新色时先在 token 中寻找。
- 不要用统一字号/字重压平层级 —— 标题与正文要有明确对比。
- 不要滥用主色:一屏多处高饱和蓝会稀释关键信号。
- 不要添加降低可读性或可访问性的装饰性效果。
- 不要在同一界面混用互不相关的视觉隐喻。
- 不要让通用跨品牌组件依赖 `--h-*` 原生 token。
