# 对话框规范

适用于全局确认、重命名、创建、分享、导入、资源选择、评审及更新等产品对话框。社区「新建发布」是布局范本。布局和字段规则由共享控件承载；业务内容由调用方提供。

## 通用尺寸

| 部位 | 规范 |
| --- | --- |
| 视口安全距离 | 四周至少 `24px`，普通面板高度上限为 `100dvh - 48px` |
| 面板圆角 | `12px` |
| 面板宽度 | 通用默认 `520px`；按内容保留确认、资源选择、工作台等业务宽度，避免一律放大 |
| 横向内容内边距 | `22px`；窄于 `560px` 的视口使用 `18px` |
| 标题栏 | 上下 `18px`，与正文之间 `1px` 实线；标题与关闭入口之间 `16px` |
| 标题 | `16px`、字重 `600`、行高 `1.5`；长标题可换行 |
| 标题说明 | `12px`、行高 `1.4`，与标题间距 `4px` |
| 类型切换 | 分段背景圆角 `8px`、内边距/间距 `4px`；选项高 `36px`、圆角 `6px`、文字 `13px / 500` |
| 正文 | 上下 `20px`；表单项之间默认 `18px`，复杂网格保留列布局 |
| 正文说明 | `13px`、行高 `1.55` |
| 底部操作栏 | 上下 `14px`，顶部 `1px` 实线，按钮间距 `8px`；空间不足时换行 |
| 操作按钮 | 高 `36px`、横向内边距 `18px`、圆角 `6px`、文字 `13px / 500` |
| 关闭按钮 | `32 × 32px`、圆角 `6px`、透明背景，放在标题栏右侧 |
| 文本输入 | 高度至少 `40px`、圆角 `6px`、内边距 `8px 12px`、文字 `14px` |

操作栏可在左侧放状态、归属说明或复选框，操作按钮靠右。字段中的删除按钮、图形选项、分页、表格及编辑器工具栏按其专用控件规范处理。

## 分区与滚动

从上至下排列四个同级区域：

1. `DialogHeader`：标题、说明和关闭入口。
2. `DialogToolbar`：类型切换或其他持续可见的控件。
3. `DialogBody`：唯一的主要内容滚动区。
4. `DialogFooter`：取消、确认等操作。

`Dialog` 默认采用 `scrollable` 布局：面板为纵向 flex；Header、Toolbar、Footer 不收缩；Body 设置 `flex: 1 1 auto`、`min-height: 0` 和 `overflow-y: auto`。内容溢出时，标题、类型切换和操作区保持可见。不要把类型切换或操作栏放在 Body 内。

`DialogToolbar` 下方必须保留 **4px 固定安全间距**。这段间距属于工具区外边距，滚动到任意位置时仍然保留。Body 自身的内容内边距另行计算。

切换业务类型后，将 Body 的 `scrollTop` 重置为 `0`，让新内容从顶部开始。业务列表内部确实需要独立滚动时，可以设置自己的滚动区。

表单可直接使用 `Dialog as="form"`。保留独立原生 `form` 时，将其标记为 `data-dialog-part="form"`，其中的 Body 与 Footer 为同级子元素；不要为了固定操作栏而断开提交按钮与表单的关联。

设置、预览和抽屉等复杂工作区保留分栏、画布和内部滚动归属，使用工作区外观；其标题和操作栏仍按通用尺寸对齐。用户主动切换的全屏预览可铺满视口。图片灯箱保留沉浸式背景，不套用普通表单的正文内边距。非模态浮层、菜单和内嵌 GenUI 卡片不属于本规范的面板布局范围。

## 实现归属

通用分区和尺寸由 [`dialog-chrome.css`](../packages/components/src/dialog-chrome.css) 维护，React 控件自动输出 `data-dialog-surface` / `data-dialog-part`。保留动画、原生表单或独立门户的既有弹窗通过同一属性契约接入，避免复制一份标题栏和操作栏样式。业务专用内容仍使用相邻 CSS Module。

应用层少量集成样式维护在 [`styles/dialogs.css`](../apps/web/src/styles/dialogs.css)，只处理邀请页的图示分栏、设置工具区、预览标题栏等业务差异。新增弹窗优先使用共享 React 控件。

## 字段与卡片

- 标签和控件左对齐；同一列的标签起点一致。
- 分类、默认图标等选择字段采用普通字段形态：标签在上，选项在下。
- 使用 `FieldGroup` 保留原生 `fieldset` / `legend` 语义；分组本身不增加卡片边框、背景或额外缩进。
- 字段标签默认字号 `13px`、字重 `500`，标签与控件之间间距 `6px`。
- 资源卡片、上传区、空态和已选文件容器使用实线描边。

## 图形选项

Logo、图标等图形单选使用 `VisualChoiceGroup`，以原图边缘作为计算基准。

| 参数 | 当前规范 |
| --- | --- |
| 默认图形尺寸 | `34 × 34px`，接入方可按资产指定尺寸 |
| 原图圆角 | 默认 `8px`，接入方与实际图形保持一致 |
| 原图之间的间距 | `16px`，空间不足时换行 |
| 默认状态 | 外框透明 |
| 悬浮状态 | 黑色 `20%`、`2px` 外描边 |
| 选中状态（含选中后悬浮） | 黑色 `60%`、`2px` 外描边 |
| 原图到外框内缘的净空 | 悬浮和选中均为 `2px` |
| 外框外缘相对原图 | 外扩 `4px` = `2px` 净空 + `2px` 线宽 |
| 外框外圆角 | 原图圆角 + `4px`；默认 `12px` |

外框通过绝对定位伪元素绘制，宽高、间距和选项位置不随状态变化。背景保持透明，不以额外底色或位移表达悬浮。选中态优先于悬浮态。

控件保留可见的键盘焦点标识。选项使用可访问名称和 `aria-pressed` 表达状态；调用方提供本地化标签、当前值和 `onChange`。禁用时禁止触发修改。

## 交互职责

- 点击或按下弹窗外的遮罩空白区域不关闭弹窗，避免误操作丢失未提交内容；独立实现的弹窗、抽屉、嵌套确认和预览灯箱遵循同一规则。
- `Dialog` 提供 `role="dialog"`、`aria-modal`、标题关联以及可选的 Escape 关闭，不提供点击遮罩关闭的开关。关闭、取消、提交成功等明确操作由接入方处理。
- 接入方提供明确的标题、关闭入口、初始焦点和关闭后的焦点返回；按业务需要管理模态范围内的焦点。
- 提交期间由接入方统一控制禁用状态和关闭策略，避免重复提交、切换类型或意外关闭。
- Portal 挂载、表单校验、失败恢复、提交和成功反馈由接入方负责。

## 范本参数

社区新建发布目前使用：宽 `700px`、高度上限 `620px`、视口安全距离 `48px`、面板圆角 `12px`、横向内容内边距 `22px`。这些尺寸由业务弹窗样式维护；其他对话框按内容选择合适尺寸。
