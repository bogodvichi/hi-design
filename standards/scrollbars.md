# 全局滚动条规范

适用于产品主文档中的普通滚动容器，包括对话框、列表、侧栏和表单。共享实现为 `OverlayScrollbars`。

## 布局与尺寸

- 使用覆盖式滚动条：原生滚动仍由容器承担，自绘轨道覆盖在内容上方，不额外占据宽度。
- 移除原生滚动条箭头；已接管容器的原生滚动条和 `scrollbar-gutter` 保留空间一并关闭。
- 完整宽度 `T` 优先沿用容器已有的 WebKit 滚动条宽度，没有可用值时为 `8px`。
- 默认滑块宽度为 `T / 2`；悬浮、拖拽时为 `T`。
- 变宽或变窄时，垂直滚动条始终右侧对齐；横向滚动条始终底部对齐。
- 垂直滚动条右侧距离容器内边缘始终为 **2px**；横向滚动条底部采用相同安全距离。
- 滑块使用圆角胶囊形态，长度随可视区域和内容比例变化；最短 `24px`，并且不超过轨道长度。

## 状态与热区

| 状态 | 滑块颜色 | 可见粗细 |
| --- | --- | --- |
| 默认 | 黑色 `40%` | `T / 2` |
| 悬浮 | 黑色 `80%` | `T` |
| 点击拖拽 | 黑色 `100%` | `T` |

**热区始终是完整宽度 `T` 的轨道。** 默认状态下滑块旁边的透明半幅也属于热区。鼠标进入普通内容区域时，不触发滚动条变宽或变色。右侧 `2px` 安全间距不属于热区。

拖拽状态优先于悬浮状态；拖拽期间即使指针离开轨道，仍保持拖拽样式。松开、取消或失去指针捕获后恢复相应状态。

粗细变化使用 `140ms`、`cubic-bezier(0.23, 1, 0.32, 1)`。系统高对比度模式下使用 `CanvasText` 保持可见性。

## 行为与生命周期

- 滚轮、键盘、触摸和程序滚动继续作用于原始容器；支持轨道点击和滑块拖拽。
- 保留 Ctrl + 滚轮的浏览器缩放行为。
- 自动发现后挂载的面板、Portal 和滚动容器；内容、尺寸或滚动位置变化后更新滑块。
- 轨道随祖先滚动区裁剪；被弹窗遮罩等其他内容覆盖的容器不展示可交互轨道。
- 已有明确隐藏滚动条策略的区域继续由原控件负责，例如标签条、聊天专用位置轨道。
- 主文档外的预览 iframe 由对应文档管理自己的滚动条；宿主接管范围是当前文档。
- 应用入口安装一次。卸载时移除观察器、事件、动画帧、自绘节点和接管标记，恢复原生样式。

## 接入与验证

React 应用在入口使用 `<OverlayScrollbars />`。同一文档保持一个实例。普通容器只需要设置自己的 `overflow`、尺寸和内容，不重复声明颜色、箭头和状态规则。

非 React 生命周期可以使用 `installOverlayScrollbars(root)`，并在退出时调用返回的清理函数；`root` 必须是当前文档中已挂载的元素。API 与示例见[开发控件与接入](components.md#覆盖式滚动条)。

验证至少覆盖：无额外占宽、默认/悬浮/拖拽颜色与粗细、热区边界、右侧对齐和 `2px` 间距、动态挂载、遮挡、拖拽释放和清理。实现测试见 [`OverlayScrollbars.test.ts`](../packages/components/tests/OverlayScrollbars.test.ts)。
