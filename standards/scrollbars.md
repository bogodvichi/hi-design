# 全局滚动条规范

当前 dev 使用原生滚动条加 CSS 的方案，覆盖产品主文档中的普通滚动容器，以及启用样式增强的 HTML 预览。共享入口为 `NativeScrollbars`。

## 布局与视觉

- 浏览器负责滚动条几何、命中、拖拽、键盘、滚轮、触摸、遮挡与裁剪；不使用 JavaScript 轨道浮层或全局布局同步。
- 所有普通滚动区域采用与社区页一致的标准原生样式：scrollbar-width: thin、透明轨道，默认滑块为黑色 18% 透明度。宽度、圆角、箭头、悬浮和拖拽状态由浏览器及操作系统决定。
- 不再要求固定像素宽度、默认/悬浮变宽、2px 安全距离、自定义热区或宽度过渡动画。默认颜色保持可见，不再通过整个内容区悬浮来显隐。
- 滑块通过 light-dark 跟随 color-scheme，在深色模式使用白色 18% 透明度；局部深色区域可通过 --od-native-scrollbar-thumb 提供浅色滑块。系统高对比度模式恢复系统配色。
- 原生滚动条可能占据布局空间；不通过负边距、全局裁切或强制关闭 scrollbar-gutter 隐藏这部分空间。容器原有 gutter 策略保持有效。
- 共享实现只使用标准 scrollbar-width / scrollbar-color，不再绘制 WebKit 伪元素。

## 兼容与生命周期

- 样式使用零容器选择器优先级，不带 !important。保留标签栏等明确隐藏策略；预览作者显式声明的标准 scrollbar 属性优先。标准属性会取代旧的 WebKit 精细样式，不改写设计源文件。
- 不主动遍历 Shadow DOM；内部样式由 Web Component 自身负责。
- 产品入口安装一次到 document.body，退出时移除自身样式和根标记。动态挂载的普通滚动容器自动受 CSS 影响，无需观察器重新发现。
- 预览 iframe 在自身 document.documentElement 安装样式。PreviewModal、FileViewer 和历史版本 srcdoc 通过 previewScrollbars 启用；URL 预览继续使用 odPreviewBridge=scrollbars 请求 daemon 增强响应。
- 不新增沙箱权限，不向设计源文件或导出内容写入样式。预览脚本只安装一次，样式随文档生命周期保留，兼容页面后退缓存恢复。
- 老的 OverlayScrollbars API 暂作原生实现的兼容别名；非 React 服务端的独立模块入口保持兼容。

## 接入与验证

页面框架必须先约束可用高度：占满窗口的 Grid 内容行使用 `minmax(0, 1fr)`，侧栏和 Flex 高度链上的可收缩节点使用 `min-height: 0`。团队列表等局部滚动区设置 `overflow-y: auto`，其列表项不压缩；不能让长列表反向撑高网格后被窗口外层裁切。普通内容页由主滚动容器承载整页滚动，标题、标签栏随正文滚动，除非对应页面另有固顶要求。

侧栏列表的滚动容器延伸到面板内边缘，滚动条的尺寸与命中由原生区域负责；列表行保留内容内边距，给行内操作按钮留出不与滚动条热区重叠的空间。底部操作不随列表滚动，按钮下方留白与左右留白一致，空的底栏不占用空间。

React 接入、手动安装与预览脚本示例见[开发控件与接入](components.md#原生滚动条)。

验证覆盖原生拖拽、动态横向溢出、缩放、原生 modal dialog、后挂载容器、页面自带样式和清理。浏览器测试必须显示原生滚动条，关闭 Playwright 的 --hide-scrollbars 默认参数。无观察器与无布局读取约束由组件测试验证；真实滚动与沙箱接入由 e2e UI 验证。
